# BetterThanMending for Horizon

Sneak-use to repair mending gear with experience.

A port of [BetterThanMending](https://github.com/legobmw99/BetterThanMending/tree/fabric) 1.3.0 by legobmw99 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (GPL-3.0-only).

Files (release [`betterthanmending-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/betterthanmending-v0.1.0)), each folder unpacked from its file:

- `betterthanmending-0.1.0.hnmod` (native source mod): `native/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
