Files (release [`safespawn-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/safespawn-v0.1.1)), each folder unpacked from its file:

- `safespawn-0.1.1.hnmod` (native source mod): `native/`
