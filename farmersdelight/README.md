# Farmer's Delight for Horizon

Farmer's Delight: stove, cooking pot, skillet, cutting board, crops, rich soil and 170 foods.

A port of [Farmer's Delight](https://github.com/MehVahdJukaar/FarmersDelight) 1.20.1-2.4.1+refabricated by MehVahdJukaar, MerchantPug to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`farmersdelight-v0.3.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/farmersdelight-v0.3.0)), each folder unpacked from its file:

- `farmersdelight_native-0.3.0.hnmod` (native source mod): `native/`
- `farmersdelight-2.4.1+horizon.2.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
