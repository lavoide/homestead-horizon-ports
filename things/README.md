# Things for Horizon

Trinkets and gadgets from Things (subset).

A port of [Things](https://github.com/glisco03/things) 0.3.3+1.20 by glisco to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`things-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/things-v0.1.1)), each folder unpacked from its file:

- `things_native-0.1.1.hnmod` (native source mod): `native/`
- `things-0.3.3-horizon.1.hmod` (content mod): `content/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
