# Emojiful for Horizon

:short_name: in chat shows the emoji (Twemoji), with completions as you type.

A port of [Emojiful](https://github.com/InnovativeOnlineIndustries/Emojiful) 4.2.0 by HorizonStudio to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`emojiful-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/emojiful-v0.1.1)), each folder unpacked from its file:

- `emojiful-0.1.1.hnmod` (native source mod): `native/`
- `emojiful_twemoji-0.1.0.zip` (resource pack): `resourcepack/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
