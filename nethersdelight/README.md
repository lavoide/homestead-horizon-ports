# Nether's Delight Refabricated for Horizon

Nether foods for Farmer's Delight: stuffed hoglin, Blackstone Stove and furnaces, propelplants, machetes (needs the Farmer's Delight port).

A port of [Nether's Delight Refabricated](https://github.com/DragonsPlusMinecraft/NethersDelightRefabricated) 1.20.1-4.1.1 by RaymondBlaze to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-2.1-only).

Files (release [`nethersdelight-v4.1.1-horizon.2`](https://github.com/lavoide/horizon-ports/releases/tag/nethersdelight-v4.1.1-horizon.2)), each folder unpacked from its file:

- `nethersdelight-4.1.1-horizon.2.hmod` (content mod): `content/`
