# Convenient Name Tags for Horizon

Name tags drop on death, can be sheared off and renamed.

A port of [Convenient Name Tags](https://www.curseforge.com/projects/662763) 1.1.0 by Mim1q to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (Apache-2.0).

Files (release [`convenientnametags-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/convenientnametags-v0.1.1)), each folder unpacked from its file:

- `convenientnametags-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
