# Sooty Chimneys for Horizon

Chimneys that smoke, with wind, soot and scraping.

A port of [Sooty Chimneys](https://github.com/mortuusars/sootychimneys) 1.3.4 by mortuusars to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`sootychimneys-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/sootychimneys-v0.1.0)), each folder unpacked from its file:

- `sootychimneys_native-0.1.0.hnmod` (native source mod): `native/`
- `sootychimneys-1.3.4.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
