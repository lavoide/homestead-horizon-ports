# Bridging Mod for Horizon

Right-click past an edge to bridge blocks out, Bedrock style.

A port of [Bridging Mod](https://github.com/CloudG360/BridgingMod) 2.5.1+1.20.1 by CG360 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`bridgingmod-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/bridgingmod-v0.1.1)), each folder unpacked from its file:

- `bridgingmod-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
