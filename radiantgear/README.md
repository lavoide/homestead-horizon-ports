# Radiant Gear for Horizon

Worn trinkets that glow give dynamic light.

A port of [Radiant Gear](https://github.com/illusivesoulworks/radiantgear) 2.1.6+1.20.1 by Illusive Soulworks to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-or-later).

Files (release [`radiantgear-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/radiantgear-v0.1.1)), each folder unpacked from its file:

- `radiantgear-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
