# Tokimi's Toolshed for Horizon

Hammers, excavators, scythes, copper buckets and other tools.

A port of [Tokimi's Toolshed](https://github.com/CozyCord/TokimisToolshed) 1.8 by Tokimi, CozyStudios to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (CC0-1.0).

Files (release [`tokimistoolshed-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/tokimistoolshed-v0.1.0)), each folder unpacked from its file:

- `tokimistoolshed_native-0.1.0.hnmod` (native source mod): `native/`
- `tokimistoolshed-1.8.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
