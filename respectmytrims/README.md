Piglins respect gold armour trims.

A port of [Respect My Trims](https://github.com/tnoctua/respectmytrims) 1.0.0+mc1.20 by N (tnoctua) to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-2.1-only).

Files (release [`respectmytrims-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/respectmytrims-v0.1.1)), each folder unpacked from its file:

- `respectmytrims-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
