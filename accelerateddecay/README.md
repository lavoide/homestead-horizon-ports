# Accelerated Decay for Horizon

Leaves decay quickly after a tree is cut.

A port of [Accelerated Decay](https://github.com/errormikey/accelerated-decay) 3.0.1+mc1.20.1 by ErrorMikey to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (GPL-3.0-only).

Files (release [`accelerateddecay-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/accelerateddecay-v0.1.0)), each folder unpacked from its file:

- `accelerateddecay-0.1.0.hnmod` (native source mod): `native/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
