# Minecraft Accelerated for Horizon

Pumpkins Accelerated: carved pumpkin faces and more.

A port of [Minecraft Accelerated](https://github.com/Cookieglue/PumpkinsAccelerated) 1.0.0 by Mari to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (CC0-1.0).

Files (release [`mcaccel-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/mcaccel-v0.1.0)), each folder unpacked from its file:

- `mcaccel_native-0.1.0.hnmod` (native source mod): `native/`
- `mcaccel-1.0.0.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
