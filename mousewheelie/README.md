# Mouse Wheelie for Horizon

Scroll items between inventories, sort with the middle button, pick the right tool.

A port of [Mouse Wheelie](https://github.com/Siphalor/mouse-wheelie) 1.16.3+mc1.20.1 by Siphalor to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (Apache-2.0).

Files (release [`mousewheelie-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/mousewheelie-v0.1.1)), each folder unpacked from its file:

- `mousewheelie-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
