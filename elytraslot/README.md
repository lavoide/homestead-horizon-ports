A port of [Elytra Slot](https://github.com/illusivesoulworks/elytraslot) 6.4.4+1.20.1 by Illusive Soulworks to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-or-later).

Files (release [`elytraslot-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/elytraslot-v0.1.1)), each folder unpacked from its file:

- `elytraslot-0.1.1.hnmod` (native source mod): `native/`
