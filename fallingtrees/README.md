# Panda's Falling Tree's for Horizon

Trees fall when their base is cut.

A port of [Panda's Falling Tree's](https://github.com/PandaMods-Dev/Pandas-Falling-Trees) 0.13.2 by The Panda Oliver to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (GPL-3.0-only).

Files (release [`fallingtrees-v0.1.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/fallingtrees-v0.1.1)), each folder unpacked from its file:

- `fallingtrees-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
