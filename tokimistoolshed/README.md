# Tokimi's Toolshed for Horizon

Hammers, excavators, scythes, copper buckets and other tools.

A port of [Tokimi's Toolshed](https://github.com/CozyCord/TokimisToolshed) 1.8 by Tokimi, CozyStudios to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (CC0-1.0).

Files (release [`tokimistoolshed-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/tokimistoolshed-v0.1.1)), each folder unpacked from its file:

- `tokimistoolshed_native-0.1.1.hnmod` (native source mod): `native/`
- `tokimistoolshed-1.8-horizon.1.hmod` (content mod): `content/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
