# Wearable lanterns for Horizon

Wearable lanterns for the trinket lantern slot.

A port of [Wearable lanterns](https://github.com/AbsentAbigail/WearableLantern) 1.0.1 by tsuki, Absent Abigail to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`trinketlantern-v1.0.1`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/trinketlantern-v1.0.1)), each folder unpacked from its file:

- `trinketlantern-1.0.1.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
