# Grind Enchantments for Horizon

Grindstones move enchantments to books.

A port of [Grind Enchantments](https://github.com/mschae23/grind-enchantments) 3.1.4+1.20.1 by mschae23 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-or-later).

Files (release [`grindenchantments-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/grindenchantments-v0.1.1)), each folder unpacked from its file:

- `grindenchantments-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
