# Trinkets for Horizon

Extra equipment slots for trinkets, in a menu on G.

A port of [Trinkets](https://github.com/emilyploszaj/trinkets) 3.7.2 by Emi, C4 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`trinkets-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/trinkets-v0.1.0)), each folder unpacked from its file:

- `trinkets_native-0.1.0.hnmod` (native source mod): `native/`
- `trinkets-3.7.2.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
