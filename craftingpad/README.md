# Crafting Pad for Horizon

A portable crafting table.

A port of [Crafting Pad](https://github.com/StrikerRockers-Mods/CraftingPad) 1.0.12 by StrikerRocker, Giselbaer to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`craftingpad-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/craftingpad-v0.1.0)), each folder unpacked from its file:

- `craftingpad_native-0.1.0.hnmod` (native source mod): `native/`
- `craftingpad-0.1.0.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
