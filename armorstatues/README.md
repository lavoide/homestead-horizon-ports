# Armor Statues for Horizon

Sneak and use an armor stand with an empty hand to pose, style and move it.

A port of [Armor Statues](https://github.com/Fuzss/armorstatues) 8.0.6 by Fuzs to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MPL-2.0).

Files (release [`armorstatues-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/armorstatues-v0.1.0)), each folder unpacked from its file:

- `armorstatues-0.1.0.hnmod` (native source mod): `native/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
