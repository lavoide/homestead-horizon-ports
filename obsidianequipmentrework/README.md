# Obsidian Equipment Reworked for Horizon

Obsidian tools and armour.

A port of [Obsidian Equipment Reworked](https://github.com/CozyCord/Obsidian-Equipment-Reworked) 1.0 by Tokimi, CozyStudios to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (CC0-1.0).

Files (release [`obsidianequipmentrework-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/obsidianequipmentrework-v0.1.0)), each folder unpacked from its file:

- `obsidianequipmentrework_native-0.1.0.hnmod` (native source mod): `native/`
- `obsidianequipmentrework-1.0.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
