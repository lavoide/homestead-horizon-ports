# Things for Horizon

Trinkets and gadgets from Things (subset).

A port of [Things](https://github.com/glisco03/things) 0.3.3+1.20 by glisco to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`things-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/things-v0.1.0)), each folder unpacked from its file:

- `things_native-0.1.0.hnmod` (native source mod): `native/`
- `things-0.3.3+1.20.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
