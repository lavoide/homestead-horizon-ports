# Invisible Frames for Horizon

Sneak-use an item frame to make it invisible.

A port of [Invisible Frames](https://github.com/Roundaround/mc-fabric-invisible-frames) 1.1.0 by Roundaround to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT).

Files (release [`invisibleframes-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/invisibleframes-v0.1.1)), each folder unpacked from its file:

- `invisibleframes-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
