# Easy Magic for Horizon

Enchanting tables keep their items and can re-roll.

A port of [Easy Magic](https://github.com/Fuzss/easymagic) 8.0.1 by Fuzs to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MPL-2.0).

Files (release [`easymagic-v0.1.1`](https://github.com/lavoide/horizon-ports/releases/tag/easymagic-v0.1.1)), each folder unpacked from its file:

- `easymagic-0.1.1.hnmod` (native source mod): `native/`

Pinned to Horizon `fdc87ae` and Horizon Mixins `e8cd0aa`.
