# Comforts for Horizon

Sleeping bags and hammocks.

A port of [Comforts](https://github.com/illusivesoulworks/comforts) 6.4.0+1.20.1 by Illusive Soulworks to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-or-later).

Files (release [`comforts-v0.1.0`](https://github.com/lavoide/homestead-horizon-ports/releases/tag/comforts-v0.1.0)), each folder unpacked from its file:

- `comforts_native-0.1.0.hnmod` (native source mod): `native/`
- `comforts-0.1.0.hmod` (content mod): `content/`

Pinned to Horizon `3fb4c31` and Horizon Mixins `e8cd0aa`.
